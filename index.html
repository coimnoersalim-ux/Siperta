Import / Export Excel

Gunakan fitur ini untuk mengimpor data masal dari file Excel. Sistem otomatis menghapus teks "L=" atau "m2". Anda juga dapat mengekspor data yang sudah rapi ke format Excel (.xlsx) untuk laporan fisik desa.

Sistem Pindah Komputer (Backup JSON)

Ingin memindahkan data dari laptop A ke laptop B?
1. Klik Backup Database (File .json terunduh). Pindahkan file ke flashdisk.
2. Di komputer tujuan, klik Restore Database.

Sistem Cerdas: Saat melakukan Restore, Anda akan diberi pilihan untuk MENGGABUNGKAN data baru dengan data lama, atau MENIMPA (menghapus) data lama.
